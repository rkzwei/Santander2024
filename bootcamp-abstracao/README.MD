## Descrição do Projeto

Este projeto tem como objetivo abstrair o conceito de um bootcamp de cursos. Foi desenvolvido em Java como parte do Bootcamp Santander Java 2024 da DIO.

### Funcionalidades Implementadas:

- Criação e definição de cursos (Curso)
- Criação e definição de mentorias (Mentoria)
- Inscrição de desenvolvedores (Dev) em bootcamps
- Progressão dos desenvolvedores nos conteúdos
- Verificação de cursos concluídos
- Impressão das informações dos desenvolvedores

As funcionalidades foram implementadas no arquivo `Main.java` e em suas subclasses.

---

## Instruções de Execução

1. Clone o repositório em sua máquina local
2. Certifique-se de ter o Java instalado em seu ambiente
3. Compile o projeto utilizando o comando `javac Main.java`
4. Execute o projeto utilizando o comando `java Main`
